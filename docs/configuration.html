Configuration & RBAC Reference

Complete reference for projectcompass.yaml, PC_<SECTION>__<KEY> environment overrides, config.py settings, Kubernetes & RAG variables, and multi-user RBAC administration.

10 • Ship's Trim & Ballast YAML + Env Precedence RBAC & Vault Security

1. Application Settings File (projectcompass.yaml)

Copy projectcompass.example.yaml to ${DATA_DIR}/projectcompass.yaml (or point PC_CONFIG_FILE to any path). SettingsLoader evaluates settings in strict precedence order: (1) Built-in Defaults → (2) YAML File → (3) PC_<SECTION>__<KEY> Environment Variables. 

# projectcompass.yaml
branding:
  app_name: "ProjectCompass Fleet"
  tagline: "Organization Is Everything®"
  logo_url: "/static/img/logo.svg"
  notice:
    enabled: false
    text: "Staging Environment"

theme:
  primary_color: "#0f172a"
  accent_color: "#38bdf8"
  dark_mode_default: true

demo:
  enabled: false

features:
  ai_chat: true
  rag: true
  k8s: true
  pipeline_builder: true
  schedules: true
  executions: true
  rawgraphs: true
  query_runner: true
  db_connections: true
  todo: true

connections:
  - name: "Analytics Warehouse"
    type: "postgresql"
    host: "warehouse.internal"
    port: 5432
    database: "analytics"
    username: "compass_ro"
    password: "${WAREHOUSE_PASSWORD}"

2. Master Environment Variables Reference (config.py)

Variable Default Subsystem Description
DATA_DIR Project root (or /app/data in Docker) Storage Root directory for `projectcompass.db`, `scheduler_jobs.db`, `rag_data/`, `Analyses/`, `Saved_data/`, and `tmp/`.
SECRET_KEY Random hex Security Flask session signing key. Set a fixed 32+ byte secret in production.
ADMIN_USERNAME & ADMIN_PASSWORD_HASH admin / empty Auth Fallback admin credentials (PBKDF2/scrypt hash from `werkzeug.security.generate_password_hash`).
API_AUTH_TOKEN Empty Auth Static Bearer token accepted alongside per-user `ApiToken` records.
DB_CONNECTIONS_KEY Auto-generated in `tmp/.db_connections.key` ConnectorX Vault URL-safe base64 32-byte Fernet key encrypting remote DB credentials in SQLite.
DB_CONNECTIONS_MAX_ROWS 100000 ConnectorX Maximum rows returned from a remote database query.
KUBECONFIG_PATH / KUBECONFIG Auto-discovered Kubernetes Path to kubeconfig file for the k0s master (`~/.kube/k0s-compass.conf`).
K8S_NAMESPACE kube-compass Kubernetes Target Kubernetes namespace where Flow ConfigMaps, Secrets, and Jobs are created.
K8S_DEFAULT_IMAGE python:3.11-slim Kubernetes Default container image used for Flow Pods when a flow does not specify `image`.
K8S_SECRET_REFS Empty Kubernetes Comma-separated Kubernetes Secret names mounted via `envFrom` into every Flow Pod.
K8S_JOB_TIMEOUT_SECONDS 3600 Kubernetes Default `activeDeadlineSeconds` applied to Kubernetes Flow Jobs.
MITHRIL_HOST http://localhost:16180 AI & RAG Base URL of the Mithril multi-model LLM and reranking server.
RAG_EMBED_BACKEND local RAG `local` (zero-cost sentence-transformers E5-small) or `mithril` (cloud embedding API).
MITHRIL_EMBED_MODEL & MITHRIL_RERANK_MODEL gemini-embedding-exp-03-07 / gemini-2.5-flash RAG Model identifiers used when Mithril embeddings or `/api/rerank` are invoked.
USE_GIT_SYNC, GIT_REPO_URL, GIT_BRANCH, GIT_TOKEN False / empty / main Git Sync Synchronizes `Analyses/` with a remote Git repository on startup and save.

3. Role-Based Access Control (RBAC) Matrix

Users managed at /admin/users (or created via /setup) are assigned one of three roles:

Capability viewer editor admin
Browse catalog, view reports, run local SQL, chat with AI/RAG ✅ Yes ✅ Yes ✅ Yes
Create/edit analyses, pipelines, DB connections, K8s flows, chains & schedules ❌ No ✅ Yes ✅ Yes
Manage users, roles, API tokens, worker drain/removal & system metrics ❌ No ❌ No ✅ Yes
