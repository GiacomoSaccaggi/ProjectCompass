Platform Overview & Ecosystem

What ProjectCompass is, the analytical fragmentation problems it solves, its 10 core subsystems, and how it sails in formation with Mithril, Scomp-Link, ConnectorX, and k0s Kubernetes.

01 • Maiden Voyage Python 3.10+ / Flask 3 k0s + Scomp-Link + Mithril

1. What is ProjectCompass?

ProjectCompass is a self-hosted analytical catalog, SQL workbench, ML pipeline studio, hybrid RAG assistant, and Kubernetes workload orchestrator built in Python. In almost every data science and engineering organization, three recurring challenges appear as soon as an analytical prototype succeeds:

  • Discoverability Drift — Reports, notebooks, SQL queries, and dashboards scatter across laptops, Git repos, and shared drives without unified metadata or full-text search.
  • Execution Fragility — Parameterized Python scripts or ML pipelines fail on colleagues' machines due to conflicting dependencies, missing secrets, or unrecorded CLI flags.
  • Context-Blind AI — Generic LLM chats cannot see the actual Python code, SQL queries, YAML metadata, or stakeholder comments inside a specific project folder.
🧭 Skipper's Log — One Racing Hull, Four Sails

ProjectCompass replaces ad-hoc scripts and scattered folders with a unified command deck: (1) Catalog & Versioning for governance, (2) DuckDB + ConnectorX + RAWGraphs for zero-friction data exploration, (3) Scomp-Link + k0s Kubernetes for reproducible execution, and (4) Mithril + Hybrid RAG for grounded AI assistance.

2. The 10 Core Subsystems

📂 1. FTS5 Analysis Catalog

Central repository of HTML reports, Jupyter Notebooks, Structured Python Analyses, and ML Pipelines with multi-dimensional filtering, SQLite FTS5 search, ratings, favorites, and comments.

⚙️ 2. Structured Execution Engine

Any analysis folder containing compass_flow.yaml and a Dockerfile becomes an executable flow with live SSE execution logs and versioned outputs.

🔗 3. Visual Pipeline Builder

Interactive drag-and-drop and DSL studio powered by scomp-link (>> operator) for data loading, cleaning, feature engineering, model training, and evaluation with version history.

🦆 4. DuckDB + ConnectorX SQL

Query uploaded CSV/SQLite files directly on disk via DuckDB read_csv_auto(), or route read-only SQL to PostgreSQL, MySQL, MariaDB, ClickHouse, Oracle, and SQL Server via ConnectorX.

📊 5. RAWGraphs Visual Studio

Push any SQL query result or uploaded CSV directly into an embedded RAWGraphs visual canvas to build alluvial diagrams, treemaps, violin plots, and custom SVG charts.

🤖 6. Sandboxed AI Data Agent

Natural-language dataset Q&A at /chat. Converts questions into pandas expressions validated via Python AST inspection (blocking import, open, exec, eval) before running on main_df.

🧠 7. Per-Analysis Hybrid RAG

Indexes each analysis folder (.py, .sql, .yaml, .md, plus DB comments) using code-aware chunking, ChromaDB vectors + BM25 lexical search, and Mithril cross-encoder reranking.

☸️ 8. k0s Kubernetes Console

Worker node management (/workers), isolated batch/v1 Pod execution, and real-time Pod log streaming (/runs). Flows are managed directly from the Analysis catalog — any analysis with compass_flow.yaml + Dockerfile is executable.

⏱️ 9. APScheduler & Webhooks

Cron-based scheduling for analyses, k8s flows, and chains with OS file-lock leader election across Gunicorn workers, plus outbound HTTP webhooks on run completion.

🔐 10. RBAC, Audit & External CLI

Role-Based Access Control (admin, editor, viewer), Bearer API tokens, full audit trail (AuditLog), and the standalone scripts/compass_cli.py automation client.

5. Who Uses ProjectCompass?

  • Data Scientists & ML Engineers — Package analyses, build reproducible scomp-link pipelines, and offload heavy training or ETL scripts to k0s worker nodes using a shared Python worker library.
  • Analytics Engineers & BI Analysts — Run DuckDB or ConnectorX SQL across local CSVs and production databases, save reusable queries, and build RAWGraphs visualizations in seconds.
  • Platform & MLOps Engineers — Manage k0s worker capacity, configure YAML/Env settings, enforce RBAC & secret policies, and automate runs via compass_cli.py or CI/CD webhooks.
  • Business & Product Stakeholders — Browse the catalog, inspect versioned HTML dashboards, run parameterized self-service reports, and ask grounded questions via per-analysis AI chat.
