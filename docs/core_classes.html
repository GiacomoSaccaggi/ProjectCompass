Complete class hierarchy, constructors, and method signatures for ProjectCompass, the cooperative inheritance chain, the ConnectorX database service, the Mithril/RAG engines, and the CLI SDK.

1. The Cooperative Inheritance Chain

2. Top-Level Facade & Data Engine

ProjectCompass(DataUtils, AnalysisUtils) — basefun.py

Instantiated once at startup as app.config['WEBAPP']. Separates code assets (dir_path) from mutable runtime storage (data_dir).

  • __init__(dir_path: str, data_dir: str | None = None) — Resolves self.project_folder and initializes all parent mixins via super().__init__(dir_path=dir_path, data_dir=resolved_data).
  • create_task_config(task_id: str, task_version: str, **kwargs) -> dict (static) — Builds a generic task configuration payload.
  • encrypt_and_compress(text: str, key: str = 'key') -> str & decrypt_and_decompress(...) -> str — Module-level XOR + zlib + Base64 helpers in basefun.py.

DataUtils — utils/data_utils.py

Manages Saved_data/ and Saved_queries/ and executes SQL queries locally or across remote databases.

Method Signature Behavior & Details
sql(sql_query: str) -> pd.DataFrame Opens an in-memory DuckDB connection, maps every .csv in Saved_data/ to read_csv_auto('/abs/path.csv') AS alias, attaches .sqlite/.db files via ATTACH ... (TYPE sqlite), executes the query, and always closes the connection in a finally block.
run_sql(sql_query: str, connection_id: int | None = None) -> pd.DataFrame Routes to local DuckDB (`self.sql`) when connection_id is None, or delegates to DbConnectionService().run_query(connection_id, sql_query) for remote ConnectorX databases.
upload_text_files(request) -> None Normalizes uploaded CSV/TSV/delimited files using form-supplied separator and header settings and saves them as clean CSVs in Saved_data/.
list_data() -> list[str] Returns dataset stem names for all .csv, .sqlite, and .db files in Saved_data/.

3. Catalog, Git Sync & HTML Injection Classes

AnalysisUtils(GitSyncUtils) — utils/analysis_utils.py

Bridges the file-based Analyses/ directory with the SQLite AnalysisRecord model and Kubernetes Flow definitions.

  • read_single_analysis(main_folder: str, folder: str) -> dict — Parses metadata.yaml and output_versions.yaml, detects compass_flow.yaml + Dockerfile , and computes UI display fields including the ⚡ Flow badge.
  • read_multiple_analysis() -> dict[str, dict] — Loads all catalog items and syncs them with SQLite and FTS5.
  • upload_new_analysis(request) -> str & modify_analysis(request) -> str — Handles web form uploads, runs pdoc, extracts imports into requirements.txt, extracts SQL from docstrings, and triggers optional Git commit/push.
  • save_k8s_flow_analysis(...) -> dict & list_k8s_flows() -> list[dict] — Persists executable Flow definitions (analyses with compass_flow.yaml + Dockerfile) and synchronizes them with `AnalysisRecord`. Flows are surfaced in the catalog at /analysis with a ⚡ Flow badge.

GitSyncUtils(HTMLUtils) — utils/git_utils.py

Provides non-interactive Git repository synchronization (`GIT_TERMINAL_PROMPT=0`) for `Analyses/` with automatic credential redaction (`_sanitize_git_text`).

  • git_init_or_clone(repo_url, branch, target_dir, token) -> bool — Clones a remote repo into `Analyses/` on startup or initializes and pulls if files already exist.
  • git_pull(target_dir, branch, token) -> bool — Pulls with `--no-rebase`; if a merge conflict occurs, aborts the merge and preserves local files safely.
  • git_commit_and_push(target_dir, message, branch, token) -> bool — Stages all changes (`git add -A`), commits as `ProjectCompass <compass@cluster.local>`, and pushes to `origin`.

HTMLUtils(K8sFlowRunnerUtils) — utils/html_utils.py

  • __init__(dir_path, data_dir=None, **kwargs) — Loads `constants.yaml`, `tool_choices.yaml`, `links.yaml`, `intro.txt`, `title.txt`, and splits `templates/header.html` by `` / `` markers into `self.html_parts`.
  • substitute_html(**kwargs) -> dict[str, str] — Renders `head`, `top_container`, and `sidebar_menu` partials with current port, branding, and feature-gate flags.
  • apply_settings(settings: PublicAppSettings) -> None — Applies branding, theme colors, and navigation overrides loaded from `projectcompass.yaml`.

4. Kubernetes 4-Tier MRO Hierarchy (utils/k8s_utils.py)

All Kubernetes cluster and workload orchestration is implemented across four single-responsibility classes in utils/k8s_utils.py:

Class Parent Key Methods & Responsibilities
BaseK8sClient object Loads kubeconfig (`KUBECONFIG_PATH` → `KUBECONFIG` → in-cluster ServiceAccount → `~/.kube/config` → `/var/lib/k0s/pki/admin.conf`), initializes `CoreV1Api` and `BatchV1Api`, and provides `k8s_ensure_namespace()`.
K8sClusterUtils BaseK8sClient Manages worker nodes: `k8s_list_nodes()`, `k8s_sync_workers_with_db()` (reconciles `Ready`, `NotReady`, `Removed`), `k8s_register_worker()`, `k8s_drain_worker()`, `k8s_delete_worker()`, and `k8s_generate_join_token()`.
K8sFlowRunnerUtils K8sClusterUtils Executes isolated `batch/v1` Jobs: creates `pc-flow-cfg-` ConfigMap (`/workspace/flow.py`, `params.json`, `requirements.txt`, `entrypoint.sh`), optional `pc-flow-sec-` Secret, and `pc-flow-job-` Job; spawns background log watcher thread (`_watch_flow_job`).
K8sFlowRunnerUtils K8sClusterUtils Orchestrates isolated Kubernetes batch/v1 Jobs: launch_flow_run(), abort_flow_run(), ConfigMap/Secret/Job lifecycle, and background log watcher threads.

5. Database Connections, Settings, RAG & CLI Classes

Module Classes / Functions Purpose
utils/db_connection_service.py DbConnectionService, TestResult Validates connection forms, encrypts secrets via CredentialVault, tests connectivity, enforces read-only SQL, and executes queries via connectorx.read_sql().
utils/credential_vault.py CredentialVault Fernet symmetric encryption wrapper for database credentials stored in SQLite.
utils/db_dialects.py BaseDbDialect (ABC), DialectRegistry, 7 concrete dialect subclasses Dialect-specific URI builders, default ports, and read-only query validators for PostgreSQL, MySQL, MariaDB, MSSQL, Oracle, ClickHouse, and SQLite.
utils/app_settings.py & utils/feature_gate.py SettingsLoader, AppSettings, FeatureGate Loads and validates projectcompass.yaml + PC_* env overrides; blocks disabled modules at request time.
utils/mithril_client.py MithrilClient HTTPX client for Mithril (`/api/generate`, `/api/chat`, `/api/embeddings`, `/api/rerank`, `/api/tags`).
utils/rag_store.py & utils/chunker.py RAGStore, chunk_analysis(), chunk_comments() Wraps `scomp_link.llm.rag.RAGPipeline` with ChromaDB persistence, BM25 hybrid retrieval, and Mithril reranking.
utils/cli_utils.py CompassAPIClient, CompassCLI Object-oriented HTTP client and `argparse` command dispatcher powering `scripts/compass_cli.py`.
