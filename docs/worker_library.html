Building the Custom Worker Library (compass_worker_kit)

Complete architectural blueprint and copy-pasteable Python SDK for building the custom library that every crew or developer creates to connect worker Pods, domain tasks, and external worker vessels to the ProjectCompass Flagship Master.

08 • Worker Kit Blueprint Dual-Layer Pod + REST SDK Strict OOP Python 3.10+

1. Why Build a Custom Worker Library?

When ProjectCompass schedules a Flow onto a k0s worker node, the master mounts your entrypoint script at /workspace/flow.py, injects parameters via ConfigMap/environment variables, attaches Kubernetes Secrets, and streams `stdout`/`stderr` back to the Master's SQLite database (`ExecutionRun`).

Rather than writing monolithic, hard-to-test scripts inside the Web UI code editor, best practice is to create a shared, installable Python package (referred to here as compass_worker_kit) that your worker Pods and external nodes import. This library serves two critical purposes:

  1. Layer 1 — Pod Execution Runtime (BaseCompassTask): Standardizes how every task running on a k0s worker Pod parses master-injected parameters (`FLOW_PARAMS_JSON`, `/workspace/params.json`, `PC_PARAM_*`), reads injected Kubernetes Secrets, emits structured telemetry, and stays 100% compatible with both Kubernetes Flows (`flow.py`) and local Structured Analyses (`compass_flow.yaml + Dockerfile`).
  2. Layer 2 — Master REST API Bridge (CompassMasterClient): Allows worker tasks (or standalone worker daemons) to authenticate back to the ProjectCompass Master via Bearer Token (`Authorization: Bearer <token>`) to pull datasets via DuckDB/ConnectorX (`POST /api/query`), trigger downstream Flows or Chains, or register/heartbeat worker nodes.

2. Exact Master-to-Worker Pod Contract

To build a library that works seamlessly with `utils/k8s_utils.py` (`K8sFlowRunnerUtils`), your code must adhere to the exact filesystem and environment contract injected into every k0s Job Pod:

Artifact / Variable Location / Format How the Master Populates It
/workspace/entrypoint.sh Read-only file (`ConfigMap` `pc-flow-cfg-<id>`) Sets `HOME=/tmp` and `PYTHONPATH=/tmp/.local/lib/python/site-packages`, runs `pip install --user --no-cache-dir -r /workspace/requirements.txt` if non-empty, then runs `exec python -u /workspace/flow.py`.
/workspace/flow.py Read-only file (`ConfigMap` `pc-flow-cfg-<id>`) The Python entrypoint script stored in `Analyses/<flow_name>/flow.py`.
/workspace/params.json Read-only JSON file Merged dictionary of the Flow's default `parameters` overlaid with run-time `parameters` passed to `POST /flows/<name>/run`.
/workspace/requirements.txt Read-only pip spec file Populated from the Flow's `pip_requirements` list (e.g., `compass-worker-kit>=0.1.0`).
FLOW_NAME & FLOW_RUN_ID Environment variables (`str`) Flow identifier and the integer primary key of `ExecutionRun` in SQLite.
FLOW_PARAMS_JSON & FLOW_PARAMS_FILE Environment variables (`str`) Raw JSON string of merged parameters and the path `/workspace/params.json`.
PC_PARAM_<UPPER_KEY> Environment variables (`str`) Individual environment variable for every parameter key (e.g. `region="EU"` → `PC_PARAM_REGION="EU"`).
Injected Secrets (`envFrom`) Environment variables (`str`) Merged keys from `K8S_SECRET_REFS` → Flow `secret_refs` → ephemeral `pc-flow-sec-<run_id>` (e.g. `PC_MASTER_URL`, `PC_API_TOKEN`, `WAREHOUSE_DSN`).

4. Complete OOP Reference Implementation

Below is the complete, copy-pasteable implementation of compass_worker_kit following ProjectCompass coding standards (inheritance-first `ABC` hierarchy, strict type annotations, guard clauses, and zero global state).

4.1 Custom Exception Hierarchy (exceptions.py)

# +------------------------------------------------------------------+
# | COMPASS WORKER KIT — EXCEPTION HIERARCHY                         |
# +------------------------------------------------------------------+
"""Domain exception hierarchy for ProjectCompass worker tasks and master SDK."""

from __future__ import annotations


class WorkerKitError(Exception):
    """Base exception for all compass_worker_kit errors."""


class ParameterContractError(WorkerKitError):
    """Raised when required Flow parameters or secrets are missing or malformed."""


class MasterBridgeError(WorkerKitError):
    """Raised when HTTP communication with the ProjectCompass Master API fails."""

4.2 Layer 2: Master REST API Bridge (client.py)

CompassMasterClient enables any worker Pod or external Linux node daemon to query datasets managed by the Master (local DuckDB CSVs or remote ConnectorX databases), trigger downstream flows, or register worker nodes: 

# +------------------------------------------------------------------+
# | COMPASS WORKER KIT — LAYER 2: MASTER REST API SDK                |
# +------------------------------------------------------------------+
"""Authenticated HTTP bridge from k0s worker nodes/Pods to ProjectCompass Master."""

from __future__ import annotations

from abc import ABC, abstractmethod
import os
from typing import Any

import httpx
import pandas as pd

from compass_worker_kit.exceptions import MasterBridgeError, ParameterContractError


class BaseMasterClient(ABC):
    """Abstract contract for communicating with the ProjectCompass Master server."""

    def __init__(
        self,
        base_url: str | None = None,
        bearer_token: str | None = None,
        timeout: float = 30.0,
    ) -> None:
        """Initialize master endpoint URL and Bearer token from args or injected Secrets."""
        resolved_url = (base_url or os.environ.get("PC_MASTER_URL", "")).strip().rstrip("/")
        resolved_token = (bearer_token or os.environ.get("PC_API_TOKEN", "")).strip()
        if not resolved_url:
            raise ParameterContractError("PC_MASTER_URL is required to connect to the Master.")
        self._base_url: str = resolved_url
        self._bearer_token: str = resolved_token
        self._timeout: float = timeout

    def _headers(self) -> dict[str, str]:
        """Build HTTP headers including Bearer token authentication."""
        headers: dict[str, str] = {
            "Accept": "application/json",
            "Content-Type": "application/json",
        }
        if self._bearer_token:
            headers["Authorization"] = f"Bearer {self._bearer_token}"
        return headers

    @abstractmethod
    def query_dataframe(self, sql: str, connection: str | int | None = None) -> pd.DataFrame:
        """Execute a read-only SQL query via the Master (DuckDB or ConnectorX) and return a DataFrame."""


class CompassMasterClient(BaseMasterClient):
    """Concrete HTTPX client interacting with ProjectCompass Master REST endpoints."""

    def _request(
        self,
        method: str,
        path: str,
        payload: dict[str, Any] | None = None,
    ) -> dict[str, Any]:
        """Perform an authenticated HTTP request against the ProjectCompass Master."""
        url = f"{self._base_url}/{path.lstrip('/')}"
        try:
            with httpx.Client(timeout=self._timeout) as client:
                response = client.request(
                    method=method.upper(),
                    url=url,
                    headers=self._headers(),
                    json=payload,
                )
        except httpx.HTTPError as exc:
            raise MasterBridgeError(f"Network error contacting Master at {url}: {exc}") from exc

        if response.status_code >= 400:
            raise MasterBridgeError(
                f"Master API {method} {path} failed ({response.status_code}): {response.text}"
            )
        return response.json()

    def query_dataframe(self, sql: str, connection: str | int | None = None) -> pd.DataFrame:
        """Fetch tabular data from Master's DuckDB or saved ConnectorX connection via POST /api/query."""
        if not sql.strip():
            raise ParameterContractError("SQL query string cannot be empty.")
        body: dict[str, Any] = {"sql": sql}
        if connection is not None:
            body["connection"] = connection
        data = self._request("POST", "/api/query", payload=body)
        return pd.DataFrame(data.get("rows", []), columns=data.get("columns"))

    def trigger_flow(
        self,
        flow_name: str,
        parameters: dict[str, Any] | None = None,
        secrets: dict[str, str] | None = None,
    ) -> dict[str, Any]:
        """Dispatch a downstream Kubernetes Flow on the Master via POST /flows/<name>/run."""
        payload: dict[str, Any] = {
            "parameters": parameters or {},
            "secrets": secrets or {},
        }
        return self._request("POST", f"/flows/{flow_name}/run", payload=payload)

    def register_worker_node(
        self,
        node_name: str,
        role: str = "worker",
        labels: dict[str, str] | None = None,
    ) -> dict[str, Any]:
        """Pre-register or heartbeat a worker node record on the Master via POST /workers/register."""
        return self._request(
            "POST",
            "/workers/register",
            payload={"name": node_name, "role": role, "labels": labels or {}},
        )

4.3 Layer 1: In-Pod Task Runtime Contract (runtime.py)

BaseCompassTask automatically resolves parameters from `/workspace/params.json`, `FLOW_PARAMS_JSON`, and `PC_PARAM_*`, provides validated secret lookup, emits structured progress lines captured by the Master's `_watch_flow_job` thread, and exposes both `run_as_flow()` (for k0s Pods) and `run_as_structured_analysis()` (for local catalog execution): 

# +------------------------------------------------------------------+
# | COMPASS WORKER KIT — LAYER 1: POD EXECUTION RUNTIME              |
# +------------------------------------------------------------------+
"""Abstract base task encapsulating the ProjectCompass k0s Pod execution contract."""

from __future__ import annotations

from abc import ABC, abstractmethod
import json
import os
from pathlib import Path
import sys
import time
from typing import Any

from compass_worker_kit.client import CompassMasterClient
from compass_worker_kit.exceptions import ParameterContractError


class BaseCompassTask(ABC):
    """Abstract base class for all workloads scheduled onto k0s workers by ProjectCompass."""

    def __init__(self, master_client: CompassMasterClient | None = None) -> None:
        """Load master-injected run metadata and parameters from the Pod environment."""
        self._flow_name: str = os.environ.get("FLOW_NAME", self.__class__.__name__)
        self._run_id: int = int(os.environ.get("FLOW_RUN_ID", "0") or 0)
        self._params: dict[str, Any] = self._load_parameters()
        self._master: CompassMasterClient | None = master_client

    @staticmethod
    def _load_parameters() -> dict[str, Any]:
        """Load merged parameters from /workspace/params.json, FLOW_PARAMS_JSON, and PC_PARAM_*."""
        merged: dict[str, Any] = {}

        # 1. Read mounted /workspace/params.json if present
        params_file = Path(os.environ.get("FLOW_PARAMS_FILE", "/workspace/params.json"))
        if params_file.is_file():
            try:
                loaded = json.loads(params_file.read_text(encoding="utf-8"))
                if isinstance(loaded, dict):
                    merged.update(loaded)
            except json.JSONDecodeError as exc:
                raise ParameterContractError(f"Invalid JSON in {params_file}: {exc}") from exc

        # 2. Overlay FLOW_PARAMS_JSON environment variable if set
        raw_json = os.environ.get("FLOW_PARAMS_JSON", "").strip()
        if raw_json:
            try:
                loaded_env = json.loads(raw_json)
                if isinstance(loaded_env, dict):
                    merged.update(loaded_env)
            except json.JSONDecodeError as exc:
                raise ParameterContractError(f"Invalid FLOW_PARAMS_JSON: {exc}") from exc

        # 3. Overlay individual PC_PARAM_<KEY> environment variables
        for env_key, env_val in os.environ.items():
            if env_key.startswith("PC_PARAM_"):
                param_key = env_key.removeprefix("PC_PARAM_").lower()
                if param_key not in merged:
                    merged[param_key] = env_val

        return merged

    def require_param(self, key: str, default: Any = None) -> Any:
        """Retrieve a required parameter or raise ParameterContractError when missing."""
        if key in self._params and self._params[key] is not None:
            return self._params[key]
        if default is not None:
            return default
        raise ParameterContractError(f"Required flow parameter '{key}' was not provided.")

    @staticmethod
    def require_secret(env_name: str) -> str:
        """Retrieve a secret injected via Kubernetes envFrom (secret_refs or inline secrets)."""
        value = os.environ.get(env_name, "").strip()
        if not value:
            raise ParameterContractError(
                f"Required Kubernetes Secret environment variable '{env_name}' is not set."
            )
        return value

    def log_progress(self, stage: str, message: str, **metrics: Any) -> None:
        """Emit structured log lines immediately flushed to the Master Kubelet log watcher."""
        payload = {
            "flow": self._flow_name,
            "run_id": self._run_id,
            "stage": stage,
            "message": message,
            "metrics": metrics,
        }
        print(f"[COMPASS_TASK] {json.dumps(payload)}", flush=True)

    @property
    def master(self) -> CompassMasterClient:
        """Lazily initialize the CompassMasterClient using injected PC_MASTER_URL and PC_API_TOKEN."""
        if self._master is None:
            self._master = CompassMasterClient()
        return self._master

    @abstractmethod
    def execute(self, params: dict[str, Any]) -> dict[str, Any]:
        """Execute domain workload on the worker node and return a JSON-serializable summary."""

    def run_as_flow(self) -> int:
        """Primary entrypoint invoked by /workspace/flow.py inside a k0s batch/v1 Job Pod."""
        start_ts = time.monotonic()
        self.log_progress("START", f"Starting flow '{self._flow_name}' (run_id={self._run_id})")
        try:
            summary = self.execute(dict(self._params))
            elapsed = round(time.monotonic() - start_ts, 3)
            self.log_progress("COMPLETED", "Flow finished successfully", elapsed_s=elapsed, result=summary)
            return 0
        except Exception as exc:
            elapsed = round(time.monotonic() - start_ts, 3)
            self.log_progress("FAILED", str(exc), elapsed_s=elapsed)
            print(f"ERROR: {exc}", file=sys.stderr, flush=True)
            return 1

    def run_as_structured_analysis(self, inputs: dict[str, Any], output_path: str) -> str:
        """Backwards-compatible adapter for local compass_flow.yaml + Dockerfile run(inputs, output_path)."""
        merged_inputs = {**self._params, **(inputs or {})}
        self._params = merged_inputs
        summary = self.execute(merged_inputs)

        out_dir = Path(output_path)
        out_dir.mkdir(parents=True, exist_ok=True)
        report_file = out_dir / "report.html"
        report_file.write_text(
            f"<h2>{self._flow_name} — Execution Summary</h2>"
            f"<pre>{json.dumps(summary, indent=2)}</pre>",
            encoding="utf-8",
        )
        return str(report_file)

5. Writing a Concrete Worker Task & 6-Line Entrypoints

Once `compass_worker_kit` is created, implementing a new workload for your k0s cluster takes just one subclass and a 6-line `flow.py`: 

# src/compass_worker_kit/tasks/churn_scoring.py
from __future__ import annotations
from typing import Any
from compass_worker_kit.runtime import BaseCompassTask


class CustomerChurnScoringTask(BaseCompassTask):
    """Score customer churn on a k0s worker node using data fetched from the Master."""

    def execute(self, params: dict[str, Any]) -> dict[str, Any]:
        region = str(self.require_param("region", default="EMEA"))
        threshold = float(self.require_param("score_threshold", default=0.65))

        self.log_progress("EXTRACT", f"Querying active customers for region={region}")
        df = self.master.query_dataframe(
            f"SELECT customer_id, tenure_months, monthly_spend FROM customers WHERE region = '{region}'"
        )

        # Deterministic scoring logic on the worker node
        high_risk_count = int((df["monthly_spend"] > (threshold * 100)).sum()) if not df.empty else 0
        self.log_progress("SCORE", "Completed worker scoring", rows=len(df), high_risk=high_risk_count)

        return {
            "region": region,
            "evaluated_customers": len(df),
            "high_risk_customers": high_risk_count,
        }

Using Your Library Inside a k0s Flow (/workspace/flow.py)

# Analyses/churn-scoring-flow/flow.py
import sys
from compass_worker_kit.tasks.churn_scoring import CustomerChurnScoringTask

if __name__ == "__main__":
    sys.exit(CustomerChurnScoringTask().run_as_flow())

Using the Exact Same Class in a Local Structured Analysis (compass_flow.yaml + Dockerfile)

# Analyses/churn-scoring-flow/analysis/compass_flow.yaml + Dockerfile
from typing import Any
from compass_worker_kit.tasks.churn_scoring import CustomerChurnScoringTask


def run(inputs: dict[str, Any], output_path: str) -> str:
    """Adapter called by ProjectCompass local Structured Analysis engine."""
    return CustomerChurnScoringTask().run_as_structured_analysis(inputs, output_path)

6. Distributing the Library to k0s Worker Nodes

You have two ways to make compass_worker_kit available inside worker Pods scheduled by ProjectCompass:

Strategy A: Runtime Installation via pip_requirements (Fastest Iteration)

When creating or updating a Flow in ProjectCompass, add your package (from PyPI, an internal package index, or a Git repository URL) to pip_requirements. The Pod's `/workspace/entrypoint.sh` installs it into `/tmp/.local` before running `/workspace/flow.py`: 

uv run python scripts/compass_cli.py --url http://<MASTER_IP>:5000 --token "$PC_API_TOKEN" \
  flows create \
  --name churn-scoring-flow \
  --code-file ./flow.py \
  --params '{"region": "EMEA", "score_threshold": 0.7}' \
  --requirements "compass-worker-kit @ git+https://github.com/your-org/compass-worker-kit.git@main" \
  --secret-refs "compass-master-Auth"

Strategy B: Pre-Baked Worker Docker Image (Production Zero-Startup Latency)

For production clusters or air-gapped k0s workers, bake compass_worker_kit and heavy scientific libraries (`pandas`, `scikit-learn`, `lightgbm`, `scomp-link`) into a custom worker image and set K8S_DEFAULT_IMAGE (or the per-flow image field): 

# Dockerfile.worker
FROM python:3.11-slim

RUN apt-get update && apt-get install -y --no-install-recommends git curl && rm -rf /var/lib/apt/lists/*
WORKDIR /opt/worker-kit

COPY pyproject.toml ./
COPY src/ ./src/
RUN pip install --no-cache-dir . scomp-link duckdb connectorx

USER 1000:1000
# Build and import the image directly into k0s containerd on each worker node
docker build -f Dockerfile.worker -t ghcr.io/your-org/compass-worker:0.1.0 .
docker save ghcr.io/your-org/compass-worker:0.1.0 | sudo k0s ctr images import -

Provisioning the Master API Secret in Kubernetes

So worker Pods can authenticate back to the Master via `CompassMasterClient` without hardcoding tokens, create a Kubernetes Secret in the kube-compass namespace and reference it in `K8S_SECRET_REFS` or the Flow's `secret_refs`: 

sudo k0s kubectl -n kube-compass create secret generic compass-master-auth \
  --from-literal=PC_MASTER_URL="http://<MASTER_IP>:5000" \
  --from-literal=PC_API_TOKEN="<YOUR_BEARER_TOKEN>"
