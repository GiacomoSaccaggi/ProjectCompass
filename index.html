🧭 Skipper's Log — Why We Built This Sloop

Data teams often drift in becalmed waters: scattered Jupyter notebooks, orphan CSVs, undocumented cron scripts, and AI assistants that hallucinate because they lack project bearings. ProjectCompass brings your entire analytical crew aboard one self-hosted racing yacht: an FTS5-indexed analysis catalog, a DuckDB + ConnectorX SQL chartroom, a visual scomp-link ML pipeline rigging loft, a per-analysis hybrid RAG navigator powered by Mithril, and a k0s Kubernetes flotilla where every Python workload sails in an isolated Pod.

⚡ 60-Second Helm Check (Quick Start)

Boot the master locally, provision a k0s control plane, or inspect your cluster from the CLI.

# 1. Install dependencies and launch ProjectCompass Master (http://localhost:5002)
uv sync
uv run python run.py

# 2. (Optional) Bootstrap a local k0s Master + Worker node & export kubeconfig
sudo ./scripts/k0s_master_setup.sh --kubeconfig-out ~/.kube/k0s-compass.conf
export KUBECONFIG=~/.kube/k0s-compass.conf

# 3. Query cluster nodes, flows, and DuckDB datasets via the External CLI
uv run python scripts/compass_cli.py --url http://localhost:5002 --token "$PC_API_TOKEN" workers list
uv run python scripts/compass_cli.py --url http://localhost:5002 --token "$PC_API_TOKEN" flows run --name etl-daily --wait
